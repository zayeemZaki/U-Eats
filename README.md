# U-Eats

A custom full-stack web platform designed and built for a local restaurant in Toledo, Ohio. This project modernizes the business's online presence, allowing customers to browse the menu and place orders directly through a dedicated web application.

[**Visit Live Website**](https://main.d20ukwqpkslt8j.amplifyapp.com/)

## Project Overview

The goal of this project was to replace a static informational page with a functional e-commerce experience. The application handles everything from showcasing the restaurant's brand and location to processing secure transactions for food orders.

## Key Features

- **Modern Information Display:** A clean, responsive landing page that highlights store hours, location, and brand identity, ensuring customers can find what they need quickly on mobile or desktop.
- **Interactive Digital Menu:** Users can easily browse food categories and items without needing to download PDF menus.
- **Online Ordering System:** A complete checkout flow allowing users to build a cart and place orders for pickup.
- **Secure Payment Processing:** Integrated Stripe API to handle credit card transactions safely and reliably.

## Technical Details

The application follows a decoupled client-server architecture:

- **Frontend:** Built with **React.js** to create a dynamic, single-page application experience.
- **Backend:** Powered by **Node.js** and **Express** to handle API requests and business logic.
- **Payments:** **Stripe** integration for handling checkout sessions.
- **Deployment:** Hosted on **AWS Amplify**.
